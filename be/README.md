# WareTrack – Backend (BE)

NestJS + TypeScript (Node.js 24), Prisma + PostgreSQL, Socket.IO, modular monolith.

- Biến môi trường mẫu: [`.env.example`](.env.example) (giá trị thật đặt ở secrets của CI/server).
- Deploy độc lập qua [`.github/workflows/be.yml`](../.github/workflows/be.yml)
  (chỉ chạy khi có thay đổi trong `be/**`).
