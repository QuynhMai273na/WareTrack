# WareTrack – UI

React 19 + TypeScript + Vite, React Three Fiber (3D), Tailwind + shadcn/ui.

- Biến môi trường build mẫu: [`.env.example`](.env.example). Giá trị thật đặt ở GitHub Variables.
- Deploy độc lập qua [`.github/workflows/ui.yml`](../.github/workflows/ui.yml)
  (chỉ chạy khi có thay đổi trong `ui/**`).
